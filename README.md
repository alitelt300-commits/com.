# FCAI-CU · Class of 25/29

## هيكل الملفات
```
index.html        الصفحة الرئيسية (الهيكل فقط)
css/style.css     التصميم والألوان
js/data.js        ⭐ البيانات: الدكاترة، الأدمنز، جدول المحاضرات (ده الملف اللي هتعدل فيه غالبًا)
js/app.js         منطق الموقع (التابات، العرض) - مش محتاج تعدله عادةً
images/hero.jpg   صورة الخلفية
```

## التعديل
- دكتور جديد: ضيف سطر في `doctors` داخل `js/data.js`
- أدمن جديد: ضيف في `admins`
- محاضرة جديدة: ضيف سطر `L("اليوم","الوقت","المادة","الدكتور",قاعة_أ,قاعة_ب)` في `lectures`
- رابط الدرايف: في `index.html` جوه قسم `id="drive"`

## الرفع
ارفع كل الملفات مع الحفاظ على الفولدرات (مثلًا على GitHub Pages أو Netlify). لازم `index.html` يكون في الجذر.
